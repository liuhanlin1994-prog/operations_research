运筹奇境 · 网页版上传说明
============================

这个 web/ 文件夹就是网站本体。整包上传到任意静态托管，学生即可在浏览器里玩。

【推荐：Cloudflare Pages（免费 · 自动 HTTPS · 国内多数可访问 · 无需备案）】
1. 打开 https://dash.cloudflare.com （注册/登录，免费）
2. 左侧：Workers & Pages → Create → 选 Pages → Upload assets（直接上传，无需 Git）
3. 起个项目名 → 把 web 文件夹里的【全部内容】拖进上传框 → Deploy
4. 等几十秒，得到网址，形如  https://你的项目名.pages.dev
5. 把网址发给学生，手机/电脑浏览器打开即玩。

【注意】
- 必须上传 web/ 里全部内容（index.html + levels/ + bgm/ + cards/），缺一不可。
- 纯静态、无服务器/数据库；每个学生进度存各自浏览器里。
- 首次打开仅下约 1.3MB（地图+开场）；点进哪关、放哪首曲才下对应文件，之后自动缓存。

【其他托管】
- Netlify / Vercel / GitHub Pages：免费但国内偏慢/不稳，不推荐给国内学生。
- 国内要飞快：腾讯云 COS / 阿里云 OSS 静态网站托管（每月几块钱；绑自定义域名需 ICP 备案）。

【更新网站】
- 改完游戏后重新运行：  node build/inject.mjs --web   会重建 web/，再重新上传一次即可。
